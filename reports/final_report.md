# Outbrain Feed Diversity Ranking — 상세 리포트

## 요약

- 세션 내 후보 관계를 학습한 모델(AUC 0.711)이 인기도 베이스라인(0.704)을 근소하게 상회
- MMR λ 조절로 hit rate와 다양성(ILD) 간 트레이드오프를 정량화, λ=0.8~0.9 구간이 실질적 최적 지점
- 세션당 후보 수는 이봉분포(4개/6개 봉우리), category confidence는 0.9대에 두 번째 봉우리 — 둘 다 EDA 없이는 안 보이던 패턴

## 문제 정의

정확도 중심 추천은 노출 콘텐츠를 좁힌다. 정확도-다양성 트레이드오프를 감이 아닌 수치로 측정해, 재랭킹 정책 설계에 쓸 수 있는 근거를 만드는 게 목표.

## 데이터

Outbrain Click Prediction (Kaggle). 세션(display) 안에서 여러 광고 후보가 동시 노출되고 하나만 클릭되는 구조 — 피드 추천의 핵심 조건과 동일. clicks_train 8,714만 행, events 2,312만 행, promoted_content 55,958건 (2016.06.14~06.28, 미국).

## 가설 검증 및 실험

### EDA

| 확인 항목 | 결과 |
|---|---|
| session당 후보 수 | 평균 5.16개, 4개/6개 지점 이봉분포 |
| category confidence | 0 근처 + 0.9~1.0 근처 이봉분포 |
| topic confidence | 0 근처 단봉, 낮은 신뢰도 집중 |
| doc-category 커버리지 | 99.68% |

- 후보 수 이봉분포 → 세션 구성에 후보군 크기를 나누는 규칙 존재 가능성. 모델을 가변 길이 세션 처리 구조로 설계
- category만 0.9대 봉우리 존재 → 문서당 확실한 주 카테고리 하나가 있다는 뜻. 베이스라인에서 confidence 최댓값 하나만 primary_category로 채택

### 베이스라인

| 방식 | AUC | MRR |
|---|---|---|
| 인기도(ad_id별 CTR) | 0.704 | 0.634 |
| 카테고리(category_id별 CTR) | 0.580 | 0.535 |

- 카테고리 단위 집계 시 개별 광고 신호 소실 확인 (원인: 여러 광고가 같은 카테고리에 묶여 CTR 편차가 평균으로 뭉개짐)
- → 광고 단위 콘텐츠 피처를 세션 맥락과 함께 보는 구조로 설계 방향 결정

### 세션 어텐션 모델

- category/topic/entity confidence → sparse 결합 → TruncatedSVD 128차원 압축 → 세션 내 후보를 Multi-head Self-Attention으로 인코딩
- 결과: AUC 0.711 (인기도 대비 +0.007)
- 격차가 작은 이유: 콘텐츠 피처만으로는 광고 크리에이티브·브랜드 인지도 등 인기도에 내재된 요인을 대체 못 함
- 그럼에도 채택: 다음 단계(MMR 재랭킹)의 유사도 계산에 필요한 콘텐츠 임베딩 확보가 목적 (인기도 점수만으로는 재랭킹 자체가 불가능)

### MMR 다양성 재랭킹

| λ | hit rate | diversity (ILD) |
|---|---|---|
| 0.5 | 0.917 | 0.953 |
| 0.6 | 0.918 | 0.952 |
| 0.7 | 0.927 | 0.950 |
| 0.8 | 0.933 | 0.947 |
| 0.9 | 0.939 | 0.942 |
| 1.0 | 0.940 | 0.936 |

- λ=0.8~0.9 구간에서 hit rate 급상승 구간 확인 → 다양성을 소폭만 양보해도 정확도 회복폭이 큰 지점
- → 서비스 적용 시 λ=0.5 등 극단값 대신 0.8~0.9를 정책 출발점으로 제안 가능
- 세션의 44%만 후보 5개 초과 → 재랭킹 효과가 후보 많은 세션에 편중. 후보 수 기준 재랭킹 여부 분기 적용 검토 가능
- 재랭킹 전후 ILD 변화를 LLM(Groq, openai/gpt-oss-20b)에 전달해 세션별 두 문장 요약 생성 — 대량 재랭킹 결과의 사람 검수용 압축

## 세 번의 방향 전환

1. **MIND → Outbrain**: MIND 데이터셋 접근 승인제 전환으로 다운로드 불가 → Outbrain으로 대체
2. **엔티티 콜드스타트 → 재랭킹 설명 생성**: entity_id가 익명화 해시로 실제 이름 확인 불가 → LLM 활용처를 재랭킹 결과 설명으로 변경
3. **유저 히스토리 GRU → 세션 어텐션**: 유저 86% 재방문 이력 없음 확인 → 개인화 시퀀스 모델 폐기, 세션 내 후보 관계 모델로 전환
