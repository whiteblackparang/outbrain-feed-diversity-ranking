# Outbrain Feed Diversity Ranking — 상세 리포트

## 문제 정의

개인화 피드 추천에서 클릭 예측 정확도를 높이는 방향과, 추천 결과의 다양성을 확보하는 방향은 서로 충돌한다. 이 트레이드오프를 감으로 판단하지 않고, 실제 데이터로 정량화할 수 있는지 확인한다.

세부적으로는 세 가지 질문에 답한다.

- 세션(같은 display_id) 내 후보 광고들의 관계를 학습한 모델이, 단순 인기도 기반 예측보다 유의미하게 나은가
- MMR 재랭킹의 λ 값을 조절할 때, 정확도(hit rate)와 다양성(ILD)이 각각 어떻게 변하는가
- 재랭킹이 세션마다 실제로 어떤 판단을 내렸는지, 사람이 일일이 확인하지 않고도 파악할 방법이 있는가

## 데이터

- 출처: Outbrain Click Prediction (Kaggle)
- 규모: clicks_train 8,714만 행, events 2,312만 행, promoted_content 55,958건
- 기간: 2016년 6월 14일 ~ 6월 28일, 미국 내 다수 퍼블리셔 사이트
- 주요 컬럼: display_id, ad_id, uuid, document_id, category_id, topic_id, entity_id, confidence_level

## 가설 검증 및 실험

### EDA

session당 후보 광고 수는 평균 5.16개(표준편차 1.85)였지만, 히스토그램으로 그려보니 매끄러운 종형 분포가 아니라 4개와 6개 지점에서 두 번 봉우리가 생기는 이봉분포였다. 평균값만 봐서는 드러나지 않던 패턴으로, 세션 구성 자체에 후보군 크기를 나누는 규칙이 있을 가능성을 시사한다.

category와 topic의 confidence_level 분포도 서로 형태가 달랐다. topic은 낮은 신뢰도(0 근처)에 압도적으로 몰려 있는 반면, category는 0 근처 외에 0.9~1.0 구간에서도 뚜렷한 두 번째 봉우리를 보였다. 즉 문서마다 확실한 주 카테고리가 하나씩 존재하는 경우가 많다는 뜻이며, 이는 베이스라인 실험에서 category 컬럼당 confidence가 가장 높은 하나만 primary_category로 뽑아 쓴 근거가 됐다.

document_id 기준 클릭 데이터와 카테고리 메타데이터 간 커버리지는 99.68%로, 조인 손실 없이 대부분의 광고에 콘텐츠 메타데이터를 매칭할 수 있었다.

### 베이스라인

- 인기도 기반 CTR(ad_id별 과거 클릭률): AUC 0.704, MRR 0.634
- 카테고리 기반 CTR(category_id별 클릭률): AUC 0.580, MRR 0.535

카테고리 단위로 집계하면 개별 광고 신호가 사라진다는 걸 이 격차로 확인했다. 처음엔 코드 버그로 의심했지만, 카테고리 하나에 여러 광고가 섞이면서 개별 광고의 CTR 편차가 평균으로 뭉개지는 것이 원인이었다.

### 세션 어텐션 모델

같은 세션 내 후보 광고들을 Multi-head Self-Attention으로 함께 인코딩하는 모델을 학습시켰다. category, topic, entity의 confidence를 sparse 행렬로 결합한 뒤 TruncatedSVD로 128차원으로 압축한 콘텐츠 임베딩을 입력으로 사용했다.

결과는 AUC 0.711로 인기도 베이스라인(0.704)을 근소하게 상회했다. 콘텐츠 피처만으로는 광고 크리에이티브나 브랜드 인지도처럼 인기도에 암묵적으로 반영된 요인을 완전히 대체하기 어렵다는 걸 시사한다.

### MMR 다양성 재랭킹

세션 어텐션 모델의 예측 점수를 기반으로, MMR(Maximal Marginal Relevance)로 top-5를 재랭킹하며 λ 값을 0.5부터 1.0까지 변화시켰다.

| λ | hit rate | diversity (ILD) |
|---|---|---|
| 0.5 | 0.917 | 0.953 |
| 0.6 | 0.918 | 0.952 |
| 0.7 | 0.927 | 0.950 |
| 0.8 | 0.933 | 0.947 |
| 0.9 | 0.939 | 0.942 |
| 1.0 | 0.940 | 0.936 |

λ를 0.5에서 1.0으로 올릴수록 hit rate는 2.3%p 상승하고 ILD는 0.017 하락한다. 세션의 44%만 후보가 5개를 초과해, 다양성 재랭킹의 실질적 효과는 후보가 많은 세션에서 더 뚜렷하게 나타난다.

재랭킹 판단 근거를 사람이 세션마다 확인하는 대신, 재랭킹 전후 ILD 변화량을 LLM(Groq, openai/gpt-oss-20b)에 전달해 두 문장 요약을 받는 방식으로 대체했다.

## 세 번의 방향 전환

1. **MIND → Outbrain**: 뉴스 추천용 MIND 데이터셋이 접근 승인제로 바뀌어 다운로드가 막혀, 광고 클릭 예측 데이터셋인 Outbrain으로 전환했다.
2. **엔티티 이름 기반 콜드스타트 → 재랭킹 설명 생성**: Outbrain의 entity_id가 익명화된 해시라 실제 이름을 알 수 없다는 걸 확인하고, LLM 활용처를 콘텐츠 이해에서 재랭킹 결과 설명으로 옮겼다.
3. **유저 히스토리 GRU → 세션 어텐션**: 유저 히스토리 기반 개인화 시퀀스 모델(GRU)을 계획했으나, 유저의 86%가 재방문 이력이 없다는 걸 확인하고 성립하지 않는다고 판단했다. 같은 세션 내 후보 간 관계를 보는 구조로 전환했다.

## 결과

- 세션 내 후보 관계를 학습하는 것이 카테고리 단위 집계보다는 유효했지만(AUC 0.711 vs 0.580), 인기도 신호만큼의 설명력을 완전히 대체하지는 못했다(0.711 vs 0.704).
- 관련성과 다양성은 명확한 트레이드오프 관계에 있으며, λ 값으로 이를 정량적으로 조절할 수 있다는 걸 확인했다.
- 데이터 분포를 먼저 확인하지 않고 모델부터 설계하면(유저 히스토리 GRU 사례), 데이터 특성과 맞지 않는 설계로 시간을 소모하게 된다는 걸 겪었다.

## 한계와 다음 단계

- 콘텐츠 기반 피처만으로는 인기도 신호를 완전히 대체하지 못했다. 광고 크리에이티브 이미지나 텍스트 임베딩을 추가하면 개선 여지가 있다.
- 세션 어텐션 모델은 세션 내 후보 수가 적을 때(4개 이하) 상대적으로 학습 신호가 약할 가능성이 있어, 후보 수별 성능 분해 분석이 필요하다.
- λ는 현재 전체 세션에 고정값으로 적용했는데, 세션별 후보 수나 카테고리 다양성에 따라 λ를 동적으로 조절하는 방식도 검토할 만하다.
